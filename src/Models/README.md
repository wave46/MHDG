# Solver models

This folder contains physics models and magnetic, heating and control input support.

- [Magnetic equilibrium input](../../docs/inputs/equilibrium.md): configuration,
  file formats, reconstruction and coordinate conventions.
- [External heating input](../../docs/inputs/heating.md): power-density profiles,
  file formats, time sampling and normalization.
- [Source schedules and density feedback](../../docs/inputs/controls.md):
  prescribed sources, chords, feedback settings and controller timing.
- [Reduced 1D transport](../../docs/models/transport-1d.md): configuration,
  diffusion and pinch models, normalization and output.
