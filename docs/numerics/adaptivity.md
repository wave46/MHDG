# Mesh adaptivity

Mesh adaptivity is configured in `ADAPT_LST`. It controls spatial mesh
resolution independently of numerical timestep selection.

## Element-count limit

```fortran
&ADAPT_LST
    ! Other adaptivity settings for the case ...
    max_elements = 0    ! Global adaptive element cap; 0 = unlimited
/
```

`max_elements` in `ADAPT_LST` optionally limits the global triangle count of
each mesh generated by adaptivity. Omission or `max_elements = 0` leaves mesh
size unlimited; negative values are rejected. Boundary elements, high-order
nodes and MPI ghosts do not count. A candidate exactly at the cap is allowed.
The check follows Gmsh's 2D generation, before high-order elevation, saving or
installing the candidate. It does not limit Gmsh's temporary generation memory
or validate the initial/restart mesh size.

An oversized candidate during Newton (including divergence, oscillation and
restart-triggered adaptation) returns a recoverable failure through the existing
timestep controller. With reduction enabled, the accepted state is restored and
the interval is halved, subject to `dt_min`. Otherwise the run stops. Halving
does not guarantee that the spatial resolution requirement will decrease.
Periodic `time_adapt` remeshing takes place after step acceptance and stops on
an oversized candidate, including in moving-equilibrium runs; it does not
retroactively retry an accepted step. Legacy frame-based runs also stop.
The cap does nothing when adaptivity is inactive.

With a cap enabled, solver fields and matrices are retained while Gmsh
generates the candidate, so rejection can leave the current mesh usable.
Unlimited runs retain the existing early memory release.

For timestep modes, reduction settings and lower bounds, see
[physical time stepping](../simulation/time-stepping.md#failure-recovery).
